# Manual do painel (para a proprietária)

Acesse `https://www.seudominio.com.br/admin`.

## Cadastrar uma peça nova
1. **Produtos → Novo produto**: nome, descrição, preço, categoria. Salve (começa como Rascunho).
2. **Fotos**: escolha a cor (se as fotos forem de uma cor específica) e envie. A primeira foto é a capa. Use “← Antes / Depois →” para ordenar. Preencha o texto alternativo.
3. **Cores, tamanhos e estoque**: marque as cores e tamanhos e clique em *Gerar combinações*. Informe o estoque de cada uma e salve.
4. Volte ao topo, mude o **Status para Ativo** e salve. Pronto: está na loja.

Dicas: *Destaque* coloca a peça na home; *Novidade* coloca o selo “Novo”. “Preço original” só para promoção verdadeira (a peça precisa ter sido vendida por aquele valor — Código de Defesa do Consumidor).

## Lançar uma coleção
Cadastre as peças, crie uma categoria se precisar e troque a **abertura da home** em *Banners da home* (foto, título e botão).

## Pedidos
- **Aguardando pagamento**: a peça está reservada; se não pagar no prazo, o pedido expira sozinho.
- **Pagamento aprovado**: separe e embale. Mude para *Em preparação* → *Enviado* (com código de rastreio) ou *Pronto para retirada*. Marque “avisar a cliente por e-mail”.
- **Requer atenção**: valor pago diferente do pedido ou pagamento depois de a reserva expirar. Confira no Mercado Pago antes de enviar.
- **Reembolsar**: botão no pedido (somente proprietária).
- **Exportar CSV** para planilhas/contabilidade.

## Cupons, frete, páginas
- **Cupons**: % / valor fixo / frete grátis, com validade, compra mínima e limite de usos.
- **Frete**: retirada na loja, entrega local (faixa de CEP de Sinop: 78550000-78559999) e envio com valor fixo.
- **Páginas e FAQ**: textos institucionais. Campos como `{{loja.cnpj}}` são preenchidos com os dados de Configurações.

## Clientes e LGPD
- Use os dados só para atender pedidos; e-mails de novidades apenas para quem autorizou (coluna “Novidades por e-mail” e menu *Newsletter*).
- Pedido de cópia dos dados → *Exportar dados*. Pedido de exclusão → *Anonimizar cadastro* (pedidos ficam guardados por obrigação fiscal).

## Segurança
Cada pessoa com seu próprio login (Usuários). Papel *Equipe* não altera configurações nem faz reembolsos. Nunca compartilhe senha.
