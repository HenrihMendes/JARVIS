# Frete

## Hoje
Formas de entrega configuráveis no painel (retirada, entrega local por faixa de CEP, envio com valor fixo), frete grátis por valor mínimo ou cupom. Todas vêm **desativadas** até a proprietária definir os valores — o sistema não inventa preços de frete.

Faixa de CEP de Sinop usada como sugestão: `78550000-78559999` (confira com os Correios).

## Próximo passo sugerido: cálculo automático
Para vender para fora de Sinop com frete calculado por peso/distância, integrar **Melhor Envio** (cotação de Correios/Jadlog com desconto, etiquetas e rastreio). Requer conta da loja, token de API e peso/dimensões de cada produto (o campo de peso já existe no banco). Estimativa: 1–2 dias de desenvolvimento.
